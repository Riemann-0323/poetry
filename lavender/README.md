# 薰衣草 · 影像

为诗作《薰衣草》生成的一部 3 分 39 秒短片（1920×1080 / 30fps / 立体声）：**[`lavender_compact.mp4`](lavender_compact.mp4)**（H.264 + AAC，87 MB。约 10 Mbps 的母版超过 GitHub 的单文件上限，可以按下文的步骤重新生成）。

画面与声音全部由本目录中的代码从零生成：没有素材库、没有采样、没有任何图像或音乐生成模型。画面是一万四千颗"花粉"粒子加上一套排版引擎，配乐是用 numpy 逐个采样点合成的。

## 构想

这首诗的声音甜得发腻：甜甜圈、抹茶千层、奶酪棒、小熊、"你最好了"。但这份甜总是差一点点。句子在不该断的地方断开，祈使句越来越急，花语说到一半就停了，最后一节写到"重力被我遗忘，晚安，晚安"。
影片想做的，就是让这种"差一点点"被看见、被听见。

- **画面：** 一整团薰衣草色的粒子，不断尝试变成诗里说出的东西：薰衣草丛、甜甜圈、千层、安睡之神的眼睛、玫瑰、小熊、星空、曲奇、月亮、雨中的乐谱、空画框、双星、地球、涟漪、一支薰衣草、藤蔓、看不到的月亮、向东的河、越拉越长的重音符号、水母降落伞、空气毯子。每一节结束时，诗句本身会碎成花粉被风吹走。
- **声音：** 一段 F 大调 3/4 拍的八音盒摇篮曲（原创旋律）。它先是甜的，然后发条慢慢松掉：越走越慢、音高下沉，最后在"薰衣草的花语是"处戛然而止。

## 文字恐怖谷：藏在里面的东西

1. **诗是被实时"打"出来的。** 全片都有一个光标在跟着字走。第六节写到"我会一直爱着你"，"你"被删掉，改成"这个世界"。
2. **花语没有说出口。** "薰衣草的花语是"之后，打出"等待"，再一个字一个字删掉，然后硬切黑屏和绝对静音，只留光标闪三下。
3. **形近字潜意识闪帧（2–4 帧）：** 薰→熏、我→找、玫→玖、绝→絶、好→妤、人→入、心→必、理→**埋**、爱→**受**，以及第二个"晚安"里的 安→**亡**（同一时刻声音会断掉 66 毫秒）。
4. **一个错音。** 第一节结尾的回声里，降 B 被换成了还原 B。第八节的旋律越来越跑调，还"忘掉"了两个音。
5. **"我为什么在写作"**：作品意识到自己是文本，于是露出了源码。
6. **重力被我遗忘**：诗句一个字一个字飘离；最后一行被推出画面右侧。配乐是谢泼德–里塞特音阶，一种听起来永远在上升、却永远到不了的声音。
7. **`Lacepocterlse`** 恰好是 `spectacle Lore` 的完整字母重排（连大写 L 都对得上）。尾声里字母会短暂地重新排列一次，再回到原样。这是我在制作时发现的巧合，不代表作者的本意。

## 重新生成

```bash
pip install numpy scipy pillow opencv-python-headless
./fetch_fonts.sh                       # Noto Serif SC、霞鹜文楷、JetBrains Mono、Cormorant
python3 audio.py score.wav             # 约 40 秒
python3 video.py render video_only.mp4 # 4 核约 10 分钟
ffmpeg -i video_only.mp4 -i score.wav -c:v copy -c:a aac -b:a 256k -shortest -movflags +faststart lavender.mp4

python3 video.py still 30.4 93.6 150.5  # 渲染任意时间点的单帧到 stills/
```

- `common.py`：诗的文本与排版、整片的时间线、逐字打字节奏（含删除）
- `video.py`：粒子形状、形变、藤蔓生长、文字尘埃、排版与故障效果、后期
- `audio.py`：八音盒、风笛、合唱、钢琴、手鼓、心跳、雨、藤蔓、故障声、谢泼德音阶、混响与母带
