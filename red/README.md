# 红色 · 影像

为诗作《红色》生成的一部 4 分 22 秒短片（1920×1080 / 30fps / 立体声）。成片在 [`red.mp4`](red.mp4)。

和《薰衣草》一样，画面与声音全部由本目录中的代码从零生成，没有用素材库、采样或任何生成模型。不同的是，这一首的画面主体是 GLSL 着色器：在软件 OpenGL（llvmpipe）上跑光线步进和光线追踪。宝石的折射与色散、巴别塔、高台、丝绸、熔岩、血肉、火、水、日冕都是这样渲染出来的。上面叠一层抗锯齿矢量绘图，再叠逐字排版，最后经过 bloom、色散、冲击波、马赛克、玻璃裂纹、故障这些后期。

## 节奏骨架

全片以 174 BPM 为网格，每行诗占 4 小节，每个字落在十六分音符上。

- 前半段是半速（87）的肉感律动，配管风琴和 808。
- 「这一局我要全下」之后进入 Drum'n'Bass。
- 第五节回到深海般的半速。
- 第六节那串意象做成一局**音游**：右边是四条轨道和判定线，主旋律的每一个音都对应谱面上落下来的一个音符，PERFECT、连击和分数都按真实谱面计数。连击冲到将近三千（对应「三千页」）后显示 ∞，然后在「无限的弃绝骑士」之后 MISS，整首歌像磁带一样停转。

## 重新生成

```bash
pip install numpy scipy pillow opencv-python-headless moderngl
apt-get install -y libegl1 libegl-mesa0      # 用于 llvmpipe 的无头 EGL
./fetch_fonts.sh
python3 audio.py score.wav                   # 约 1 分钟
python3 video.py render video_only.mp4       # 4 进程约 30 分钟
ffmpeg -i video_only.mp4 -i score.wav -c:v copy -c:a aac -b:a 256k -shortest -movflags +faststart red.mp4

python3 video.py still 50.5 135.3 218.1      # 渲染任意时间点的单帧到 stills/
```

- `common.py`：诗、174 BPM 网格、逐字时间、鼓的编排、音游谱面（音频和画面共用）
- `scenes.glsl`：24 个场景着色器
- `engine.py`：GL 管线（场景 → 合成 → bloom → 调色）
- `draw.py`：矢量意象库
- `typo.py`：逐字砸落的排版、海报字、标题与签名
- `video.py`：镜头表、节拍驱动的后期、多进程渲染
- `audio.py`：配乐与音效
